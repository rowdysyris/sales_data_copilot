📌 Section 1

What Is This Project?

Imagine you have a Senior Data Analyst sitting next to you. You can ask them anything about your sales data — "Which product is losing money?", "How are we doing this year?", "Should we give this customer a bigger discount?" — and they give you a smart, data-backed answer in seconds.

That's exactly what this project builds. An AI-powered Sales Analyst Copilot that you can upload your sales data to, ask any question, and get a senior-level analyst response — complete with numbers, insights, and recommendations.

🎯 One line summary: Upload your sales CSV → Ask any question in plain English → Get a senior data analyst answer with real numbers and business recommendations.
📁

Upload Any CSV

Drop in your sales data file. The app reads it, understands it, and prepares it for analysis automatically.

💬

Ask in Plain English

No SQL, no formulas. Just type your question like you'd ask a colleague — even messy questions work.

🧠

Get Analyst Answers

Every answer includes the data, the insight, and a recommendation. Just like a real senior analyst would.

Export Reports

Download PDF reports, Excel files, and Power BI ready data packages with one click.

Most companies have data but can't use it. Here's the problem:

Generic BI tools don't answer real questions

Power BI and Tableau show charts, but they can't answer "Is our discount strategy working?" or "Which state should we exit?"

4

This project solves all three

Available 24/7, answers in plain English, gives real business recommendations backed by your actual data.

How Does It Work?

Here is the journey from your question to the answer — step by step:

👤 User uploads CSV file
↓
📋 App reads & profiles the data
Detects columns, types, date range, nulls
↓
💬 User types a question in plain English
↓
🧭 Intent Interpreter reads the question
Figures out what operation is needed
↓
Group By?
Rank?
Correlate?
Filter?
↓
🐼 Pandas calculates the exact numbers
Only relevant aggregated data — not all 9994 rows
↓
🤖 AI receives question + relevant data
Explains, polishes, and adds business context
↓
✅ Structured Answer Delivered
Headline → Data → Insight → Recommendation
🔑 Key insight: The AI never calculates numbers itself. Pandas (Python) does all the math. The AI only explains the results in natural language. This means the numbers are always accurate — not hallucinated.
🏆 Section 4

The 4 Tiers of Intelligence

We built the AI analyst's intelligence in 4 levels — like leveling up a video game. Each tier is harder than the last.

Tier 1

🔵 Sanity Checks

Basic questions any spreadsheet can answer. Tests if the app can read the data correctly.

  • How many rows are there?
  • What columns exist?
  • Any missing values?
  • Total sales and profit?
Tier 2

🟢 Analyst Level

Questions that require grouping, ranking, and derived metrics. Real analyst work.

  • Most profitable category?
  • Profit margin by region?
  • Top 5 products by revenue?
  • How does discount affect profit?
Tier 3

🔴 Hard Questions

Multi-step reasoning, date analysis, business judgment. Requires deep thinking.

  • Year over year growth?
  • % of unprofitable orders?
  • Which state should we exit?
  • Is our discount strategy working?
Tier 4

🟣 Real World Messy

Vague, informal, ambiguous questions. How a real manager actually talks.

  • "How are we doing?"
  • "What's killing our profit?"
  • "Furniture is doing well right?"
  • "Tell me about discounts"
⚡ Why 4 tiers? Most AI tools only handle Tier 1 and Tier 2. What makes this project special is Tier 3 (business judgment) and Tier 4 (messy real-world questions). That's what replaces a real analyst.

Technical Architecture

Here's what happens inside the app when a question is asked:

The Question Flow

Python / JS Flow # Step 1: User uploads CSV df = pd.read_csv("sales_data.csv") # Step 2: Auto-detect columns columns = detectColumns(df) # → { sales: "Sales", profit: "Profit", date: "Order Date", ... } # Step 3: User asks a question question = "Which region is most profitable?" # Step 4: Route the question route = routeQuestion(question, columns) # → { operation: "group_by", columns: ["Region","Profit"], metric: "raw" } # Step 5: Prepare only relevant data data = prepareDataForAI(question, df, route) # → { West: {profit: $108K}, East: {profit: $91K}, ... } # Step 6: Send to AI with system prompt answer = callAI(question, data, systemPrompt) # Step 7: Return structured answer # HEADLINE: West region is the most profitable... # DATA: West $108K > East $91K > South $46K > Central $39K # INSIGHT: West accounts for 37% of total profit... # RECOMMENDATION: Increase sales force in West region...

Tech Stack

🐍

Python + Pandas

All calculations, aggregations, and data processing. Pandas handles the math so numbers are always accurate.

🤖

Claude / OpenAI API

Only used to explain results and add business context. Never used for calculations.

🌐

Streamlit / React

The frontend interface where users upload files, ask questions, and view results.

📊

Plotly / Recharts

Interactive charts for the dashboard — bar charts, line charts, scatter plots.

📄

ReportLab / FPDF

Generates professional PDF reports with KPI cards, charts, and management plans.

📁

OpenPyXL

Creates multi-sheet Excel reports with formatted tables and charts.

The System Prompt

This is the instruction we give the AI to make it behave like a senior analyst:

System Prompt """ You are a Senior Data Analyst with 10 years experience. You will be given a user question and ONLY the relevant pre-aggregated data needed to answer that specific question. RULES: - Answer ONLY what was asked. Nothing else. - Never return generic stats for every question. - Always use $ for currency. Never use ₹. - If asked about margin, calculate profit/sales*100. - If asked about top N, always rank and return exactly N items. - If asked about correlation, show how variables change together. - Never say you cannot analyze. Always answer from the data. - If user assumes something wrong, correct it politely with data. ALWAYS STRUCTURE YOUR ANSWER LIKE THIS: INTERPRETATION: What I understood you to be asking ANSWER: Direct response to the question DATA: The exact numbers that prove it INSIGHT: What this means for the business RECOMMENDATION: What action to take """

💬 Section 9

Real Q&A Examples

Here's exactly what the app answers for different types of questions:

Which category is the most profitable?
HEADLINE
Technology is the most profitable category with $145,454.95 in total profit.
DATA
Technology: $145,454.95 profit (17.38% margin)
Office Supplies: $122,490.80 profit (17.03% margin)
Furniture: $18,451.27 profit (2.49% margin)
INSIGHT
Furniture generates good revenue but almost no profit. Its 2.49% margin is dangerously thin — one bad discount campaign could wipe it out entirely.
RECOMMENDATION
Double down on Technology and Office Supplies. Review Furniture pricing strategy — especially Tables which are actively losing money.
Our furniture business is doing well right?
INTERPRETATION
You're assuming Furniture is performing well. Let me check the data.
ANSWER
Actually, Furniture is the weakest category. The data tells a different story than you might expect.
DATA
Furniture profit margin: 2.49% — lowest of all 3 categories
Tables sub-category: -$17,725 (actively losing money)
Bookcases: also negative profit
Technology margin: 17.38% — 7x better than Furniture
RECOMMENDATION
Furniture needs urgent review. Stop discounting Tables — every discounted Tables order makes the loss worse. Consider whether Tables should remain in the product portfolio.
How many non unique datasets are there?
INTERPRETATION
Non-unique can mean two things. I'll address both.
ANSWER — Meaning 1: Fully Duplicate Rows
Zero. There are no completely duplicate rows in this dataset.
ANSWER — Meaning 2: Rows Sharing the Same Order ID
4,985 rows share an Order ID. The dataset has 9,994 rows but only 5,009 unique orders — because one order can contain multiple products, each appearing as a separate row.
RECOMMENDATION
When calculating order-level metrics like Average Order Value, always group by Order ID first — otherwise you'll double-count orders with multiple products.
What is killing our profit?
HEADLINE
Two main profit killers: aggressive discounting and the Tables sub-category.
DATA
Killer 1 — Discounts above 40%: -$99,558.59 in losses
Killer 2 — Tables sub-category: -$17,725.48 total loss
Killer 3 — 1,871 orders (18.72%) are unprofitable
Killer 4 — Cubify 3D Printer: -$8,879 single product loss
RECOMMENDATION
Stop all discounts above 30% immediately. This single action could recover nearly $100K in annual profit.

Glossary — Words You'll See in This Project

WordWhat It Means in Simple Terms
CSVA spreadsheet file saved as plain text. Excel can open it. It's the most common data format.
PandasA Python library that reads and processes spreadsheet data. Like Excel formulas but in code.
KPIKey Performance Indicator. A number that tells you how the business is doing. Example: Total Profit.
Profit MarginWhat % of revenue is actual profit. If you sell $100 and margin is 12%, you keep $12.
EDAExploratory Data Analysis. Looking at data to understand what's in it before asking questions.
System PromptInstructions you give the AI before the conversation starts. Tells it how to behave.
APIA way for your code to talk to another service. Like calling Claude/ChatGPT from Python.
HallucinationWhen AI makes up a number that doesn't exist. We prevent this by using Pandas for all math.
StreamlitA Python tool that turns Python scripts into web apps in minutes. No HTML/CSS needed.
AggregationCombining many rows into one number. Example: Sum all sales per region.
Group BySplitting data into groups and calculating something for each. Like pivot tables in Excel.
CorrelationWhether two things move together. Example: When discount goes up, does profit go down?
YoYYear over Year. Comparing this year's number to last year's to see growth.
DAXA formula language used in Power BI to calculate metrics. Like Excel formulas for Power BI.
GitA tool that saves versions of your code so you can go back if something breaks.
CI/CDContinuous Integration — automatically tests your code every time you make a change.
