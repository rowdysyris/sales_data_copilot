# Senior Analyst Power BI Dashboard Blueprint

Use the app's **Power BI Dashboard** tab to generate the full data model, DAX measures, Power Query template, and theme.

Pages:

1. Executive Overview — sales, profit, margin, loss orders, trend, category/region performance.
2. Profit Intelligence — sales vs profit, discount bands, decomposition tree, loss drivers.
3. Product Portfolio — stars, volume drivers, problem products, niche winners.
4. Customer Intelligence — loyal customers, profitable customers, unprofitable customers.
5. Regional Performance — weak regions, high-sales low-margin geographies.
6. Discount & Margin Control — high-discount orders and margin leakage.

Senior analyst goal: the dashboard must explain why performance changed, not only report what happened.
